## 🎮 Game Overview

Super Pirate World is a 2D action-platform game inspired by classic arcade adventures. The player takes control of a brave pirate and must move through multiple stages, avoid traps, battle enemies, and collect valuable rewards to progress.

The gameplay combines:

- smooth character movement
- jumping and platform navigation
- enemy AI and attack mechanics
- coin collection and score tracking
- damage and health system
- animated game objects and layered backgrounds
- sound effects and immersive game atmosphere

## 🚀 What Makes This Game Exciting?

The experience is designed to feel dynamic and engaging. Each level challenges the player with a mix of movement, timing, and strategy. Whether it's jumping over dangerous gaps, attacking foes, or collecting hidden rewards, the game encourages quick thinking and precision.

The project demonstrates how a simple idea can grow into a complete interactive game using essential game development principles.

## 🕹️ Controls

- A / D or Left / Right: Move
- W / Up / Space: Jump
- J / Attack Key: Attack enemies
- Esc: Quit the game

## 🧩 Main Features

- Smooth horizontal movement and jumping physics
- Enemy patrols and combat
- Coin collection system
- Health and damage mechanics
- Tile-based level design
- Animated sprites and effects
- Multiple game stages
- Background music and sound effects
- Object-oriented Python structure

## ▶️ How to Run

1. Install Python on your system.
2. Install the required libraries:

```bash
pip install pygame pytmx
```

3. Run the game from the project directory:

```bash
cd code_complete
python main.py
```
